# SI-GiKu

## Deskripsi Project

Sistem Informasi Genbi UNIKU (SI-GiKu) dibangun menggunakan framework Laravel untuk menyediakan solusi manajemen organisasi yang modern dan terstruktur. Aplikasi ini mencakup:

- **Manajemen User & Hak Akses:** Kontrol akses berbasis peran (RBAC) untuk pengurus dan anggota.
- **Manajemen Proker:** Pencatatan, perencanaan, dan pelacakan program kerja.
- **Sistem Kehadiran (Absensi):** Automasi pencatatan kehadiran anggota pada setiap kegiatan atau acara.
- **Data Organisasi:** Pengelolaan informasi divisi, prodi, dan data anggota Genbi secara sentral.
- **Pelaporan:** Ekspor data ke format PDF dan Excel untuk kebutuhan administratif.

## Tech Stack

- **Framework:** Laravel 12
- **Database:** MySQL
- **Auth:** Laravel Breeze & Sanctum
- **Tools:** DomPDF/MPDF (PDF generation), Maatwebsite Excel (Spreadsheet handling), Spatie Laravel Permission (RBAC)
